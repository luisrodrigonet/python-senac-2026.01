# 📕 Exercício 1 -  Consolidação de Dados (Lista, Dicionário e Contagem)

Dada uma lista de dicionários representando pedidos, calcule o valor total e a quantidade de itens únicos. 
Utilizando a estrutura do django Exiba a lista, o valor calculado e a quantidade de itens únicos em uma página web

**Dados:**

```python
pedidos = [
    {"produto": "Laptop", "preco": 3000, "quantidade": 1},
    {"produto": "Mouse", "preco": 50, "quantidade": 2},
    {"produto": "Teclado", "preco": 150, "quantidade": 1},
    {"produto": "Laptop", "preco": 3000, "quantidade": 1} # Pedido duplicado ou novo item
]
```


## 📊 Resolução do Exercício

### 1. Cálculos dos Dados

**Valor Total:**
- Laptop: 3000 × 1 = R$ 3.000
- Mouse: 50 × 2 = R$ 100
- Teclado: 150 × 1 = R$ 150
- Laptop (duplicado): 3000 × 1 = R$ 3.000
- **Total = R$ 6.250**

**Itens Únicos:** Laptop, Mouse, Teclado = **3 produtos distintos**

## 🐍 Código Django

### **views.py** - Processamento dos Dados

```python
from django.shortcuts import render

def consolidacao_pedidos(request):
    # Lista de pedidos
    pedidos = [
        {"produto": "Laptop", "preco": 3000, "quantidade": 1},
        {"produto": "Mouse", "preco": 50, "quantidade": 2},
        {"produto": "Teclado", "preco": 150, "quantidade": 1},
        {"produto": "Laptop", "preco": 3000, "quantidade": 1}
    ]
    
    # Cálculo do valor total
    valor_total = 0

    for p in pedidos:
        subtotal = p["preco"] * p["quantidade"]
        valor_total = valor_total + subtotal
    
    # Contagem de itens únicos
    #produtos_unicos = set(p["produto"] for p in pedidos)

    produtos_unicos = []
    for p in pedidos:
        produto = p["produto"]
        if produto not in produtos_unicos:
            produtos_unicos.append(produto)
    
    quantidade_unicos = len(produtos_unicos)
    
    # Contexto para o template
    context = {
        'pedidos': pedidos,
        'valor_total': valor_total,
        'quantidade_unicos': quantidade_unicos,
        'produtos_unicos': list(produtos_unicos)
    }
    
    return render(request, 'pedidos.html', context)
```
