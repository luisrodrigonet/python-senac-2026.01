# Aula 13 - List Views - Admin - Login e Logout

Nesta aula, usaremos o conteúdo das tabelas que foram inseridas de maneira manual e que deverão ser colocadas e exibidas na página “template”.  

Observe se cada aluno conseguiu até este momento entender a ligação entre back end e front end. 

Quase no fim da escolha do candidato para a vaga de full Stack, a empresa precisa exibir os dados que são cadastrados dentro do back end nas tabelas previstas no template produto.  

	• Integração back end e front end 
	• Personalização do admin
	• Publicação do conteúdo 
	
Após o término desta tarefa, reúna os alunos e levante um debate sobre as possíveis melhorias que podem ser feitas dentro do sistema. 

No  momento, é crucial observar como estão sendo criados o controle de acesso através do administrador para cada usuário do sistema.
