# 07.02 🐍 Introdução ao Framework Django 

Esta aula apresenta as principais características do `framework Django`, guia a instalação e configuração do ambiente de desenvolvimento e detalha a criação de um projeto Django, incluindo sua estrutura. 

## :one: Apresentação do Framework 

O `Django` é um **framework** web de alto nível para `Python`, projetado para desenvolvimento rápido, seguro e escalável. 

Suas principais características incluem:

1. **Arquitetura MVT (Model-View-Template)**: Separação clara entre modelos de dados, lógica de negócios e apresentação.
1. **ORM (Object-Relational Mapping)**: Permite interagir com bancos de dados usando objetos Python, sem escrever SQL diretamente.
1. **Admin Automático**: Interface administrativa gerada automaticamente para gerenciar dados.
1. **Segurança Integrada**: Proteção contra vulnerabilidades como SQL Injection, XSS e CSRF.
1. **Escalabilidade**: Usado por grandes empresas como Instagram e Pinterest.
1. **DRY (Don't Repeat Yourself)**: Promove a reutilização de código.
1. **Baterias Incluídas**: Inclui ferramentas para autenticação, formulários, URLs, templates, entre outros.

> 🤖 **Django 5.2**, a versão mais recente em julho de 2025, traz melhorias em desempenho, suporte a Python 3.12 e novos recursos, como validação avançada de formulários e integração otimizada com bancos de dados assíncronos.

## :two: Instalação e Configuração do Ambiente

🏗️ **OBS**: os passos 2.1 e 2.2 já foram realizados anteriormente, mas são citados como referência do processo

### 2.1 Pré-requisitos

* Python 3.12 instalado (verifique com `python --version`).
* Gerenciador de pacotes `pip` atualizado.
* Ambiente virtual para isolar dependências.

### 2.2 Passos para Configuração

1. **Criar um ambiente virtual**:

   ```bash
   mkdir c:\_django\
   python -m venv dj-senac-env
   source dj-senac-env/bin/activate  # Linux/Mac
   dj-senac-env\Scripts\activate     # Windows
   ```

2. **Instalar o Django 5.2**:

   ```bash
   pip install django
   ```

3. **Verificar a instalação**:

   ```bash
   django-admin --version
   ```

   Deve retornar `5.2.4`.
   
   

## :three: **Modulos adicionais (opcional)**:

Ao desenvolver aplicações web com **Django**, muitas vezes precisamos de funcionalidades que vão além do que o *framework* oferece por padrão. Para isso, existem pacotes de terceiros que ajudam a resolver problemas comuns no desenvolvimento web.


 🎯 **`django-extensions`**: é uma coleção de ferramentas adicionais para o framework Django que amplia suas funcionalidades, **facilitando o desenvolvimento, depuração e manutenção** de projetos. Ele **não é essencial**, mas é altamente recomendado para desenvolvedores que buscam produtividade e recursos avançados
  

🐍 **Instalação:**

```bash
    pip install django-extensions
```

---

 🎯  **`django-crispy-forms`** (Organizando e Estilizando Formulários) este é um pacote que facilita a renderização de formulários no Django, especialmente quando queremos integrar com frameworks de CSS como **Bootstrap**.
    
Seus benefícios incluem:

1. **Formatação** automática de formulários
2. Integração com **Bootstrap** (4 e 5)
3. Menos código HTML **repetitivo**
4. Melhor experiência de desenvolvimento

🐍 **Instalação:**
```bash
pip install django-crispy-forms
```
---

 🎯  **`django-debug-toolbar`** (Ferramenta Depuração) esta é uma ferramenta de desenvolvimento que mostra informações detalhadas sobre as requisições feitas à sua aplicação Django. É extremamente útil para **depurar** e **otimizar** a aplicação durante o desenvolvimento.

Seus benefícios incluem:

- Mostra **tempo de execução** de cada requisição
- Mostra **queries** SQL executadas
- Exibe **headers, cookies, sessões**, etc.
- Ajuda a encontrar gargalos de performance


🐍 **Instalação:**
```bash
pip install django-debug-toolbar
```

---

 🎯  **`django-widget-tweaks`** (Personalização Fina de Widgets de Formulário), este modulo permite que você personalize atributos dos campos de formulários diretamente nos templates HTML, sem alterar o modelo do formulário.

Seus benefícios incluem:

- Adicionar classes, IDs, placeholders, etc. nos campos do formulário
- Útil para integrar com frameworks de UI como Bootstrap
- Não precisa modificar o formulário no Python

🐍 **Instalação:**
```bash
pip install django-widget-tweaks
```

---

 🎯   **`Pillow`** (Manipulação de Imagens) esta é a biblioteca padrão do Python para manipulação de imagens. No Django, ele é necessário para trabalhar com campos de upload de imagem (`ImageField`).

Seus benefícios incluem:

- Permite upload de imagens
- Redimensionamento, recorte, rotação, etc.
- Trabalha com formatos como JPEG, PNG, BMP, etc.

🐍 **Instalação:**
```bash
pip install pillow
```

---

 🎯  **`python-decouple`** (Gerenciamento Seguro de Configurações) este pacote é usado para **separar configurações sensíveis** do código, como senhas, chaves de API, etc. Ele permite que você leia essas variáveis de um arquivo `.env` ou do ambiente do sistema.

Seus benefícios incluem:

- Mantém segredos fora do código
- Facilita o gerenciamento de ambientes (desenvolvimento, produção)
- Compatível com `.env`

🐍 **Instalação:**
```bash
pip install python-decouple
```

 📚 **Resumo sobre os modulos adicionais**

| Pacote               | Finalidade Principal                      | Uso Comum                                    |
| -------------------- | ----------------------------------------- | -------------------------------------------- |
| django-crispy-forms  | Estilizar e organizar formulários         | Integrar formulários com Bootstrap           |
| django-debug-toolbar | Depurar e analisar requisições            | Ver SQL, headers, templates e performance    |
| django-widget-tweaks | Personalizar widgets no template          | Adicionar classes, placeholders, etc.        |
| pillow               | Manipular imagens                         | Trabalhar com ImageField e uploads           |
