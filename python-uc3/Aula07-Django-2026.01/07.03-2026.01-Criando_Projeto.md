# 07.03 🏗️ Criando um Projeto Django 5.2 do Zero

Nesta aula, vamos aprender o passo a passo para:
- Criar um **projeto** Django
- Criar um **app** dentro do projeto
- **Executar o servidor** de desenvolvimento

Vamos utilizar **Python 3**, **Django 5.2**, e ao final você terá uma estrutura básica de projeto pronta.

## 🧰 Requisitos Iniciais

Antes de começar, certifique-se de que você tem instalado:

- **Python 3.11+** (verifique com `python --version` ou `python3 --version`)
- **Pip** (gerenciador de pacotes do Python)
- **Django 5.2** (vamos instalar agora mesmo)

## 🏗️ Passo 1: Criando o Projeto Django

O **projeto** em Django é a unidade principal que engloba toda a aplicação. Ele contém as configurações gerais do site, como banco de dados, apps instalados, idioma, fuso horário, etc.

### 🔧 Comando para criar o projeto

Para criar um novo pojeto devemos utilizar o comando abaixo.

```bash
django-admin startproject core .
```

> **Importante:** Repare no **ponto final (.)** no final do comando. Ele significa que o projeto será criado **na pasta atual**. Se você esquecer o ponto, uma nova pasta chamada `meu_projeto` será criada dentro da sua pasta atual.

### 📁 Estrutura criada

Após executar o comando, você verá os seguintes arquivos:

```
app-exemplo/
├── manage.py
└── core/
    ├── __init__.py
    ├── settings.py
    ├── urls.py
    └── wsgi.py
```

#### 📄 Descrição dos arquivos:

- **manage.py:** Script usado para executar comandos do Django (como rodar o servidor, criar apps, migrar banco de dados etc.)
- **settings.py:** Configurações principais do projeto (instalação de apps, configurações de banco de dados, segurança, etc.)
- **urls.py:** Define as URLs do site (rotas)
- **wsgi.py:** Configuração usada para servidores web
- **__init__.py:** Arquivo que indica que a pasta é um pacote Python

## 🧩 Passo 2: Criando um App Django

Em Django, os **apps** são componentes reutilizáveis que realizam funções específicas dentro do projeto. Por exemplo, você pode ter apps para gerenciar usuários, notícias, produtos, etc.

### 🔧 Comando para criar um app

```bash
python manage.py startapp paginas
```

> Substitua `meu_app` pelo nome do seu app (ex: blog, loja, usuarios)

### 📁 Estrutura criada

Após esse comando, uma nova pasta será criada:

```
paginas/
├── migrations/
├── __pycache__/
├── admin.py
├── apps.py
├── models.py
├── tests.py
└── views.py
```

#### 📄 Descrição dos principais arquivos:

- **views.py:** Define as funções ou classes que retornam páginas (respostas HTTP)
- **models.py:** Define as estruturas do banco de dados (tabelas)
- **urls.py:** (não existe ainda) Você pode criar para definir as URLs do app
- **admin.py:** Registra modelos para exibição no painel administrativo
- **apps.py:** Configuração específica do app

### 🔄 Registrando o app no projeto

Para que o Django reconheça o app, é necessário registrá-lo no arquivo `settings.py`.

Abra `meu_projeto/settings.py` e procure a seção `INSTALLED_APPS`. Adicione seu app ao final da lista:

```python
INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
    
    
    'meu_app', # <--- Seu app aqui
]
```


## 🚀 Passo 3: Testando o Servidor de Desenvolvimento

O Django vem com um servidor web embutido, ideal para testes durante o desenvolvimento. Vamos executá-lo para ver se tudo está funcionando.

### 🔧 Comando para rodar o servidor

```bash
python manage.py runserver
```

> Se tudo der certo, você verá uma mensagem como:
```
Starting development server at http://127.0.0.1:8000/
Quit the server with CONTROL-C.
```

### 🌐 Acessando o site

Abra o navegador e acesse:

```
http://127.0.0.1:8000/
```

Você verá a página inicial padrão do Django com a mensagem:

> **The install worked successfully! Congratulations!**

Parabéns! Seu projeto está rodando!

---

## 📌 Dicas Finais

- Sempre que criar um novo app, lembre-se de registrá-lo em `INSTALLED_APPS`.
- O arquivo `manage.py` é seu principal aliado para comandos do Django.
- Use o `runserver` sempre que quiser testar suas alterações localmente.
- Para parar o servidor, pressione **Ctrl + C** no terminal.


## ✅ Resumo dos Comandos

| Ação | Comando |
|------|---------|
| Instalar Django | `pip install django==5.2` |
| Criar projeto | `django-admin startproject meu_projeto .` |
| Criar app | `python manage.py startapp meu_app` |
| Rodar servidor | `python manage.py runserver` |
