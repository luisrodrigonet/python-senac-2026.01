# Aula 12 — Django ORM: Managers 🏗️

O **Manager** é a porta de entrada do seu modelo para o banco de dados. Ele retorna `QuerySet`s, que podem ser filtrados, ordenados, anotados e encadeados; no Django 6.1, a forma mais recomendada de criar consultas reutilizáveis é definir métodos em um `QuerySet` customizado e expô-los com `QuerySet.as_manager()` ou `Manager.from_queryset()`. 

Nesta aula, usaremos os modelos `Categoria` e `Receita` para criar consultas como **receitas publicadas**, **por categoria**, **por tempo de preparo** e **mais recentes**.

## 1. O que é um Manager?

Um `Manager` é uma interface que permite **consultar e manipular registros** de um modelo. Por padrão, todo modelo Django recebe o manager `objects`.

```python
from django.contrib.auth.models import User
from django.db import models


class Receita(models.Model):
    titulo = models.CharField(max_length=200)
    publicada = models.BooleanField(default=False)
    autor = models.ForeignKey(
        User,
        on_delete=models.CASCADE,
        related_name="receitas",
    )

    class Meta:
        verbose_name = "Receita"
        verbose_name_plural = "Receitas"
        ordering = ["-data_publicacao"]


# O Manager padrão é criado automaticamente:
# Receita.objects
```

- `Receita` é a **classe do modelo**.
- `Receita.objects` é o **Manager**.
- `Receita.objects.all()` retorna um **QuerySet**.
- O QuerySet ainda **não executa uma consulta imediatamente**: ele é avaliado quando você itera sobre ele, converte em lista, usa `len()`, `bool()` ou chama métodos como `get()`.

> 💡 **Regra prática:** 
> 
> - O `Manager` representa o ponto de partida da consulta; 
> - O `QuerySet` representa a consulta em construção.
>
> ---

## 2. Manager padrão: `objects`

O manager padrão `objects` é uma instância de `models.Manager()`. Ele fornece os métodos mais usados para consultar, criar, atualizar e remover registros. 

```python
# Recupera todas as receitas
todas_as_receitas = Receita.objects.all()

# Recupera apenas receitas publicadas
receitas_publicadas = Receita.objects.filter(publicada=True)

# Recupera uma receita pelo ID
receita = Receita.objects.get(pk=1)

# Cria uma receita
receita = Receita.objects.create(
    titulo="Bolo de chocolate",
    ingredientes="Farinha\nAçúcar\nChocolate",
    modo_preparo="Misture e asse por 40 minutos.",
    tempo_preparo=45,
    autor=usuario,
)

# Atualiza todas as receitas não publicadas
Receita.objects.filter(publicada=False).update(publicada=True)

# Remove registros
Receita.objects.filter(publicada=False).delete()
```

### 2.1. Métodos essenciais

| Método | Retorno | Uso principal |
|---|---|---|
| `all()` | `QuerySet` | Recupera todos os registros. |
| `filter(**kwargs)` | `QuerySet` | Recupera registros que atendem às condições. |
| `exclude(**kwargs)` | `QuerySet` | Recupera registros que **não** atendem às condições. |
| `get(**kwargs)` | Instância do modelo | Recupera **exatamente um** registro. |
| `first()` | Instância ou `None` | Recupera o primeiro registro do QuerySet. |
| `last()` | Instância ou `None` | Recupera o último registro do QuerySet. |
| `exists()` | `bool` | Verifica se existe ao menos um registro. |
| `count()` | `int` | Conta os registros. |
| `create(**kwargs)` | Instância | Cria e salva um objeto. |
| `update(**kwargs)` | `int` | Atualiza registros em massa. |
| `delete()` | Tupla | Remove registros em massa. |

### 2.2. Exemplo com `Categoria`

```python
# Todas as categorias
categorias = Categoria.objects.all()

# Busca uma categoria pelo nome
sobremesa = Categoria.objects.get(nome="Sobremesa")

# Verifica se existe uma categoria
existe_sobremesa = Categoria.objects.filter(nome="Sobremesa").exists()

# Conta categorias cadastradas
total_categorias = Categoria.objects.count()
```

> ⚠️ **Atenção:** 
> 
> - `get()` lança `DoesNotExist` se nenhum registro for encontrado e `MultipleObjectsReturned` se houver mais de um resultado. 
> - Para buscas que podem retornar zero ou vários registros, prefira `filter()`.
>
> --- 

## 3. Manager customizado simples

Você pode **criar um** `Manager` que altera o **QuerySet inicial** retornado por ele. Para isso, sobrescreva `get_queryset()`.

```python
from django.contrib.auth.models import User
from django.db import models


class ReceitaPublicadaManager(models.Manager):
    """Manager que retorna apenas receitas publicadas."""

    def get_queryset(self):
        # super().get_queryset() retorna o QuerySet padrão do modelo.
        # O filtro é aplicado antes de qualquer outro encadeamento.
        return (
            super()
            .get_queryset()
            .filter(publicada=True)
        )


class Receita(models.Model):
    titulo = models.CharField(max_length=200)
    ingredientes = models.TextField(
        help_text="Informe um ingrediente por linha."
    )
    modo_preparo = models.TextField(
        help_text="Descreva o passo a passo do preparo."
    )
    tempo_preparo = models.PositiveIntegerField(
        help_text="Tempo total de preparo, em minutos."
    )
    data_publicacao = models.DateTimeField(auto_now_add=True)
    publicada = models.BooleanField(default=False)

    categorias = models.ManyToManyField(
        Categoria,
        related_name="receitas",
        blank=True,
    )

    autor = models.ForeignKey(
        User,
        on_delete=models.CASCADE,
        related_name="receitas",
    )

    # Manager padrão: retorna todas as receitas.
    objects = models.Manager()

    # Manager customizado: retorna apenas receitas publicadas.
    publicadas = ReceitaPublicadaManager()

    class Meta:
        verbose_name = "Receita"
        verbose_name_plural = "Receitas"
        ordering = ["-data_publicacao"]

    def __str__(self):
        return self.titulo
```

### 3.1. Uso

```python
# Todas as receitas, publicadas ou não
todas = Receita.objects.all()

# Apenas receitas publicadas
publicadas = Receita.publicadas.all()

# Receitas publicadas com tempo de preparo menor ou igual a 30 minutos
receitas_rapidas = Receita.publicadas.filter(tempo_preparo__lte=30)
```

### 3.2. Parâmetros e detalhes

- `get_queryset()` deve retornar um `QuerySet`.
- `super().get_queryset()` recupera o QuerySet base antes das personalizações.
- `filter(publicada=True)` aplica uma condição SQL `WHERE publicada = true`.
- O manager `publicadas` **não substitui** o `objects`; ele é um manager adicional.
- Mantenha `objects` como manager padrão, especialmente porque o Django Admin e algumas ferramentas esperam que ele exista.

> 💡 **Boa prática:** 
> 
> - use `objects` para acesso completo ao modelo
> - crie managers adicionais com nomes expressivos, como `publicadas`, `rascunhos` ou `recentes`.
>
> ---

## 4. Manager com métodos customizados

Também é possível adicionar métodos ao Manager. Eles são úteis para consultas recorrentes, como “receitas rápidas” ou “receitas de uma categoria”.

```python
from django.contrib.auth.models import User
from django.db import models
from django.db.models import Count, Q


class ReceitaManager(models.Manager):
    """Manager com consultas reutilizáveis para o modelo Receita."""

    def publicadas(self):
        """Retorna apenas receitas publicadas."""
        return self.filter(publicada=True)

    def nao_publicadas(self):
        """Retorna apenas rascunhos."""
        return self.filter(publicada=False)

    def rapidas(self, minutos=30):
        """
        Retorna receitas com tempo de preparo menor ou igual ao limite.

        :param minutos: Tempo máximo de preparo, em minutos.
        """
        return self.filter(tempo_preparo__lte=minutos)

    def por_categoria(self, categoria):
        """
        Retorna receitas relacionadas a uma categoria.

        :param categoria: Instância de Categoria ou ID da categoria.
        """
        return self.filter(categorias=categoria)

    publicadas.boolean = True
```

```python
class Receita(models.Model):
    # ... campos anteriores ...

    objects = ReceitaManager()

    class Meta:
        verbose_name = "Receita"
        verbose_name_plural = "Receitas"
        ordering = ["-data_publicacao"]
```

### 4.1. Uso

```python
# Receitas publicadas
Receita.objects.publicadas()

# Receitas com até 30 minutos de preparo
Receita.objects.rapidas(30)

# Receitas de uma categoria específica
sobremesa = Categoria.objects.get(nome="Sobremesa")
Receita.objects.por_categoria(sobremesa)

# Encadeamento: receitas publicadas, rápidas e de uma categoria
Receita.objects.publicadas().rapidas(30).por_categoria(sobremesa)
```

### 4.2. Por que o encadeamento funciona?

O método `publicadas()` retorna um `QuerySet`. Como `rapidas()` e `por_categoria()` também retornam QuerySets, é possível encadeá-los:

```python
Receita.objects
    .publicadas()
    .rapidas(30)
    .por_categoria(sobremesa)
```

Isso gera uma única consulta SQL com todas as condições combinadas.

## 5. QuerySet customizado

Um `QuerySet` customizado é a melhor escolha quando os métodos representam **filtros e transformações de consulta**. Ele permite reutilizar os métodos tanto no manager quanto em QuerySets intermediários.

```python
from django.contrib.auth.models import User
from django.db import models
from django.db.models import Count, Q


class ReceitaQuerySet(models.QuerySet):
    """QuerySet com filtros reutilizáveis para Receita."""

    def publicadas(self):
        """Retorna apenas receitas publicadas."""
        return self.filter(publicada=True)

    def nao_publicadas(self):
        """Retorna apenas receitas não publicadas."""
        return self.filter(publicada=False)

    def rapidas(self, minutos=30):
        """
        Retorna receitas com preparo rápido.

        :param minutos: Tempo máximo de preparo, em minutos.
        """
        return self.filter(tempo_preparo__lte=minutos)

    def por_categoria(self, categoria):
        """
        Filtra receitas por uma categoria.

        :param categoria: Instância de Categoria ou ID da categoria.
        """
        return self.filter(categorias=categoria)

    def recentes(self, limite=10):
        """
        Retorna as receitas mais recentes.

        :param limite: Quantidade máxima de registros retornados.
        """
        return self.order_by("-data_publicacao")[:limite]

    def com_autor(self):
        """
        Otimiza consultas que acessam o autor da receita.

        Evita o problema N+1 ao buscar o autor de cada receita.
        """
        return self.select_related("autor")

    def com_categorias(self):
        """
        Otimiza consultas que acessam as categorias das receitas.

        Evita consultas adicionais para cada relação N:N.
        """
        return self.prefetch_related("categorias")

    def com_total_categorias(self):
        """
        Anota cada receita com o número de categorias relacionadas.
        """
        return self.annotate(
            total_categorias=Count("categorias", distinct=True)
        )
```

```python
class Receita(models.Model):
    # ... campos anteriores ...

    objects = ReceitaQuerySet.as_manager()

    class Meta:
        verbose_name = "Receita"
        verbose_name_plural = "Receitas"
        ordering = ["-data_publicacao"]
```

### 5.1. Uso

```python
# Receitas publicadas e rápidas
Receita.objects.publicadas().rapidas(30)

# Receitas publicadas com autor e categorias pré-carregados
receitas = (
    Receita.objects
    .publicadas()
    .com_autor()
    .com_categorias()
)

# Receitas com contagem de categorias
receitas = Receita.objects.com_total_categorias()

for receita in receitas:
    print(receita.titulo, receita.total_categorias)
```

### 5.2. Explicando os métodos

| Método | Função | Quando usar |
|---|---|---|
| `filter()` | Adiciona condições à consulta | Para restringir resultados. |
| `order_by()` | Define a ordenação | Para ordenar por um ou mais campos. |
| `select_related()` | Usa SQL `JOIN` para relações `ForeignKey` e `OneToOneField` | Para acessar `receita.autor` sem consultas extras. |
| `prefetch_related()` | Faz consultas separadas e relaciona os resultados em Python | Para relações `ManyToManyField` e `ForeignKey` inversas. |
| `annotate()` | Adiciona campos calculados ao QuerySet | Para contagens, somas, médias e outras agregações. |
| Fatiamento `[:limite]` | Limita resultados | Para listagens, rankings e paginação simples. |

> ⚠️ **Importante:** 
> 
> - `select_related()` é ideal para `ForeignKey`; 
> - `prefetch_related()` é ideal para `ManyToManyField`. 
> - Usar o método correto evita consultas desnecessárias.
>
> ---

## 6 `QuerySet.as_manager()`

`QuerySet.as_manager()` cria um Manager que possui automaticamente os métodos públicos definidos no QuerySet customizado. É a abordagem mais simples e recomendada quando você quer apenas consultas reutilizáveis. 

```python
class ReceitaQuerySet(models.QuerySet):
    def publicadas(self):
        return self.filter(publicada=True)

    def rapidas(self, minutos=30):
        return self.filter(tempo_preparo__lte=minutos)


class Receita(models.Model):
    # ... campos anteriores ...

    objects = ReceitaQuerySet.as_manager()
```

```python
# Os métodos do QuerySet também podem ser chamados pelo Manager.
Receita.objects.publicadas().rapidas(30)

# E também em QuerySets intermediários.
Receita.objects.filter(autor=usuario).publicadas().rapidas(30)
```

### 6.1. Regras de cópia dos métodos

Ao usar `as_manager()`, o Django copia métodos do QuerySet para o Manager segundo estas regras: 

- Métodos públicos são copiados por padrão.
- Métodos privados, iniciados com `_`, não são copiados por padrão.
- Métodos com `queryset_only = False` são sempre copiados.
- Métodos com `queryset_only = True` nunca são copiados.
- `QuerySet.delete()` não é copiado para o Manager, pois a exclusão em massa deve ser usada com cautela.

```python
class ReceitaQuerySet(models.QuerySet):
    def publicadas(self):
        """Disponível tanto no Manager quanto no QuerySet."""
        return self.filter(publicada=True)

    def _internas(self):
        """Não é copiada para o Manager por ser privada."""
        return self.filter(publicada=False)

    def apenas_interno(self):
        """Não é copiada para o Manager."""
        return self.filter(publicada=False)

    apenas_interno.queryset_only = True
```

## 7. `Manager.from_queryset()`

Use `Manager.from_queryset()` quando precisar de **métodos exclusivos do Manager** além dos métodos do QuerySet. Ele cria uma subclasse do Manager com os métodos do QuerySet copiados. 

```python
from django.contrib.auth.models import User
from django.db import models


class ReceitaQuerySet(models.QuerySet):
    """Métodos disponíveis no Manager e no QuerySet."""

    def publicadas(self):
        return self.filter(publicada=True)

    def rapidas(self, minutos=30):
        return self.filter(tempo_preparo__lte=minutos)


class ReceitaManager(models.Manager):
    """Métodos exclusivos do Manager."""

    def criar_rascunho(self, titulo, autor, **campos):
        """
        Cria uma receita ainda não publicada.

        :param titulo: Título da receita.
        :param autor: Instância de User.
        :param campos: Outros campos opcionais do modelo.
        """
        return self.create(
            titulo=titulo,
            autor=autor,
            publicada=False,
            **campos,
        )

    def publicar_todas(self):
        """Publica todas as receitas que ainda estão como rascunho."""
        return self.filter(publicada=False).update(publicada=True)


class Receita(models.Model):
    # ... campos anteriores ...

    objects = ReceitaManager.from_queryset(ReceitaQuerySet)()

    class Meta:
        verbose_name = "Receita"
        verbose_name_plural = "Receitas"
        ordering = ["-data_publicacao"]
```

### 7.1. Uso

```python
# Método do QuerySet, disponível também no Manager
Receita.objects.publicadas()

# Método exclusivo do Manager
Receita.objects.criar_rascunho(
    titulo="Lasanha à bolonhesa",
    autor=usuario,
    ingredientes="Massa\nCarne moída\nMolho de tomate",
    modo_preparo="Monte as camadas e asse.",
    tempo_preparo=90,
)

# Publica todos os rascunhos
Receita.objects.publicar_todas()

# Encadeamento com métodos do QuerySet
Receita.objects.publicadas().rapidas(45)
```

### 7.2. `as_manager()` ou `from_queryset()`?

| Situação | Recomendação |
|---|---|
| Apenas filtros e consultas reutilizáveis | `QuerySet.as_manager()` |
| Filtros reutilizáveis e criação/atualização centralizada | `Manager.from_queryset()` |
| Consulta com regra de negócio que precisa do modelo | `Manager` customizado |
| Consulta que deve funcionar após outros filtros | `QuerySet` customizado |
| Método que não deve aparecer no Manager | `queryset_only = True` no QuerySet |

## 8. Exemplo completo com seus modelos

```python
from django.contrib.auth.models import User
from django.db import models
from django.db.models import Count, Q


class Categoria(models.Model):
    """Representa uma categoria de receita, como Sobremesa ou Jantar."""

    nome = models.CharField(max_length=100)

    class Meta:
        verbose_name = "Categoria"
        verbose_name_plural = "Categorias"
        ordering = ["nome"]

    def __str__(self):
        return self.nome


class ReceitaQuerySet(models.QuerySet):
    """Consultas reutilizáveis para o modelo Receita."""

    def publicadas(self):
        """Retorna apenas receitas publicadas."""
        return self.filter(publicada=True)

    def rascunhos(self):
        """Retorna apenas receitas não publicadas."""
        return self.filter(publicada=False)

    def rapidas(self, minutos=30):
        """
        Retorna receitas com tempo de preparo limitado.

        :param minutos: Tempo máximo de preparo, em minutos.
        """
        return self.filter(tempo_preparo__lte=minutos)

    def por_categoria(self, categoria):
        """
        Retorna receitas relacionadas a uma categoria.

        :param categoria: Instância de Categoria ou ID da categoria.
        """
        return self.filter(categorias=categoria)

    def por_autor(self, autor):
        """
        Retorna receitas de um autor específico.

        :param autor: Instância de User ou ID do usuário.
        """
        return self.filter(autor=autor)

    def recentes(self, limite=10):
        """
        Retorna as receitas mais recentes.

        :param limite: Quantidade máxima de registros.
        """
        return self.order_by("-data_publicacao")[:limite]

    def com_autor(self):
        """Carrega o autor junto com cada receita."""
        return self.select_related("autor")

    def com_categorias(self):
        """Carrega as categorias junto com cada receita."""
        return self.prefetch_related("categorias")

    def com_total_categorias(self):
        """Adiciona o total de categorias de cada receita."""
        return self.annotate(
            total_categorias=Count("categorias", distinct=True)
        )


class Receita(models.Model):
    """Representa uma receita publicada no sistema."""

    titulo = models.CharField(max_length=200)

    ingredientes = models.TextField(
        help_text="Informe um ingrediente por linha."
    )

    modo_preparo = models.TextField(
        help_text="Descreva o passo a passo do preparo."
    )

    tempo_preparo = models.PositiveIntegerField(
        help_text="Tempo total de preparo, em minutos."
    )

    data_publicacao = models.DateTimeField(auto_now_add=True)

    publicada = models.BooleanField(default=False)

    categorias = models.ManyToManyField(
        Categoria,
        related_name="receitas",
        blank=True,
    )

    autor = models.ForeignKey(
        User,
        on_delete=models.CASCADE,
        related_name="receitas",
    )

    # Manager padrão com métodos do QuerySet customizado.
    objects = ReceitaQuerySet.as_manager()

    class Meta:
        verbose_name = "Receita"
        verbose_name_plural = "Receitas"
        ordering = ["-data_publicacao"]

    def __str__(self):
        return self.titulo
```

## 9. Boas práticas 🏆

- Prefira `QuerySet.as_manager()` para filtros reutilizáveis.
- Use `Manager.from_queryset()` apenas quando houver métodos exclusivos de Manager.
- Mantenha `objects` como manager principal do modelo.
- Dê nomes claros aos métodos: `publicadas()`, `rapidas()`, `por_categoria()`.
- Retorne sempre `QuerySet` nos métodos de consulta, permitindo encadeamento.
- Use `select_related()` para `ForeignKey` e `prefetch_related()` para `ManyToManyField`.
- Não coloque regras de negócio complexas no Manager se elas pertencem ao domínio da aplicação; Managers devem principalmente organizar consultas.
- Escreva testes para managers e QuerySets, especialmente para filtros, ordenações e agregações.

```python
class ReceitaQuerySet(models.QuerySet):
```

```python
    Receita.objects
    .publicadas()
    .annotate(total_categorias=Count("categorias", distinct=True))
    .order_by("-total_categorias")[:5]
)
```

A documentação oficial do Django explica que `QuerySet.as_manager()` cria um Manager com cópia dos métodos públicos do QuerySet e que `Manager.from_queryset()` é indicado quando o projeto precisa combinar um Manager customizado com um QuerySet customizado.
