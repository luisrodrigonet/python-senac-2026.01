# 🎯 Aula 12 — Desafio: Model e Templates

Neste desafio, você criará a base de dados de uma loja fictícia chamada **Pé na Estrada**, especializada em calçados. O objetivo é modelar `produtos`, `clientes`, `endereços`, `pedidos`, `itens de pedido` e `avaliações` usando **Django Models**, aplicar migrações e disponibilizar tudo no **Django Admin**.

O Django usa *models* para descrever tabelas do banco de dados em Python; `ForeignKey`, `OneToOneField` e `ManyToManyField` representam relacionamentos entre tabelas. 

## 🧩 O que você vai construir 

| Modelo | Função no sistema | Relacionamento |
|---|---|---|
| `Categoria` | Agrupa produtos por tipo de uso | Um produto pertence a uma categoria |
| `Produto` | Representa um calçado à venda | Pertence a uma `Categoria` |
| `Cliente` | Perfil estendido do usuário autenticado | Ligado a `User` por `OneToOneField` |
| `EnderecoEntrega` | Endereço para receber pedidos | Pertence a um `Cliente` |
| `Pedido` | Representa uma compra | Pertence a um `Cliente` e a um endereço |
| `ItemPedido` | Produto comprado dentro de um pedido | Pertence a um `Pedido` e a um `Produto` |
| `ComentarioAvaliacao` | Avaliação de um produto por um cliente | Liga um `Cliente` a um `Produto` |

A modelagem abaixo segue boas práticas de Django: campos obrigatórios, relacionamentos explícitos, `on_delete` definido e nomes claros para acesso reverso.

## 🗃️ 2. Criando os models

Crie ou substitua o conteúdo de `produtos/models.py` pelo código abaixo.

```python
# produtos/models.py

from decimal import Decimal

from django.contrib.auth.models import User
from django.db import models


class Categoria(models.Model):
    """
    Agrupa produtos por tipo de uso.

    Exemplos:
    - Esportivo
    - Casual
    - Social
    """

    # Nome obrigatório da categoria.
    # max_length=100 limita o campo a 100 caracteres no banco de dados.
    nome = models.CharField(
        max_length=100,
        unique=True,  # Impede duas categorias com o mesmo nome
        verbose_name="Nome",
    )

    # TextField é indicado para textos longos.
    # blank=True permite que o campo fique vazio em formulários.
    # null=True permite valor nulo no banco de dados.
    descricao = models.TextField(
        blank=True,
        null=True,
        verbose_name="Descrição",
    )

    class Meta:
        # Nome legível exibido no Django Admin.
        verbose_name = "Categoria"
        verbose_name_plural = "Categorias"

        # Ordena as categorias em ordem alfabética pelo nome.
        ordering = ["nome"]

    def __str__(self):
        # Representação textual do objeto.
        return self.nome


class Produto(models.Model):
    """
    Representa um calçado disponível para venda.
    """

    categoria = models.ForeignKey(
        to=Categoria,
        # CASCADE: ao excluir a categoria, os produtos vinculados também são excluídos.
        on_delete=models.CASCADE,
        # Nome usado para acessar os produtos de uma categoria.
        # Exemplo: categoria.produtos.all()
        related_name="produtos",
        verbose_name="Categoria",
    )

    nome = models.CharField(
        max_length=150,
        verbose_name="Nome do produto",
    )

    descricao = models.TextField(
        blank=True,
        null=True,
        verbose_name="Descrição",
    )

    # DecimalField é o campo correto para valores monetários.
    # Nunca use FloatField para dinheiro, pois pode gerar imprecisões.
    # max_digits=10 permite até 10 dígitos no total.
    # decimal_places=2 reserva duas casas para centavos.
    preco = models.DecimalField(
        max_digits=10,
        decimal_places=2,
        verbose_name="Preço",
    )

    quantidade_estoque = models.PositiveIntegerField(
        default=0,
        verbose_name="Quantidade em estoque",
    )

    # Define automaticamente a data e hora de criação.
    criado_em = models.DateTimeField(
        auto_now_add=True,
        verbose_name="Criado em",
    )

    # Atualiza a data e hora sempre que o produto for salvo.
    atualizado_em = models.DateTimeField(
        auto_now=True,
        verbose_name="Atualizado em",
    )

    class Meta:
        verbose_name = "Produto"
        verbose_name_plural = "Produtos"
        ordering = ["nome"]

    def __str__(self):
        return self.nome


class Cliente(models.Model):
    """
    Perfil estendido do usuário padrão do Django.

    Cada Cliente está ligado a apenas um User.
    """

    class Sexo(models.TextChoices):
        """
        Opções inclusivas para o campo sexo.
        """

        FEMININO = "F", "Feminino"
        MASCULINO = "M", "Masculino"
        NAO_INFORMADO = "N", "Prefiro não informar"
        OUTRO = "O", "Outro"

    # OneToOneField cria uma relação um-para-um.
    # Um User pode ter apenas um Cliente.
    # CASCADE: se o User for excluído, o Cliente também será.
    usuario = models.OneToOneField(
        to=User,
        on_delete=models.CASCADE,
        related_name="cliente",
        verbose_name="Usuário",
    )

    telefone = models.CharField(
        max_length=20,
        blank=True,
        null=True,
        verbose_name="Telefone",
    )

    # ImageField exige a biblioteca Pillow.
    # pip install pillow
    foto = models.ImageField(
        upload_to="clientes/fotos/",
        blank=True,
        null=True,
        verbose_name="Foto de perfil",
    )  

    sexo = models.CharField(
        max_length=1,
        choices=Sexo.choices,
        default=Sexo.NAO_INFORMADO,
        verbose_name="Sexo",
    )

    nome_social = models.CharField(
        max_length=150,
        blank=True,
        null=True,
        verbose_name="Nome social",
    )

    data_nascimento = models.DateField(
        blank=True,
        null=True,
        verbose_name="Data de nascimento",
    )

    cpf = models.CharField(
        max_length=14,
        unique=True,
        verbose_name="CPF",
    )

    class Meta:
        verbose_name = "Cliente"
        verbose_name_plural = "Clientes"

    def __str__(self):
        return self.usuario.get_full_name() or self.usuario.username


class EnderecoEntrega(models.Model):
    """
    Endereço utilizado para entrega de pedidos.

    Um cliente pode ter vários endereços.
    """

    cliente = models.ForeignKey(
        to=Cliente,
        on_delete=models.CASCADE,
        related_name="enderecos_entrega",
        verbose_name="Cliente",
    )

    logradouro = models.CharField(
        max_length=200,
        verbose_name="Logradouro",
    )

    numero = models.CharField(
        max_length=20,
        verbose_name="Número",
    )

    complemento = models.CharField(
        max_length=100,
        blank=True,
        null=True,
        verbose_name="Complemento",
    )

    bairro = models.CharField(
        max_length=100,
        verbose_name="Bairro",
    )

    cidade = models.CharField(
        max_length=100,
        verbose_name="Cidade",
    )

    estado = models.CharField(
        max_length=2,
        verbose_name="Estado",
    )

    cep = models.CharField(
        max_length=9,
        verbose_name="CEP",
    )

    class Meta:
        verbose_name = "Endereço de entrega"
        verbose_name_plural = "Endereços de entrega"
        ordering = ["cliente", "cidade"]

    def __str__(self):
        return f"{self.logradouro}, {self.numero} - {self.cidade}/{self.estado}"


class Pedido(models.Model):
    """
    Representa uma compra realizada por um cliente.
    """

    class Status(models.TextChoices):
        """
        Situações possíveis de um pedido.
        """

        PENDENTE = "pendente", "Pendente"
        PAGO = "pago", "Pago"
        ENVIADO = "enviado", "Enviado"
        ENTREGUE = "entregue", "Entregue"
        CANCELADO = "cancelado", "Cancelado"

    cliente = models.ForeignKey(
        to=Cliente,
        on_delete=models.CASCADE,
        related_name="pedidos",
        verbose_name="Cliente",
    )

    endereco_entrega = models.ForeignKey(
        to=EnderecoEntrega,
        on_delete=models.PROTECT,
        related_name="pedidos",
        verbose_name="Endereço de entrega",
    )

    status = models.CharField(
        max_length=20,
        choices=Status.choices,
        default=Status.PENDENTE,
        verbose_name="Status",
    )

    criado_em = models.DateTimeField(
        auto_now_add=True,
        verbose_name="Criado em",
    )

    atualizado_em = models.DateTimeField(
        auto_now=True,
        verbose_name="Atualizado em",
    )

    class Meta:
        verbose_name = "Pedido"
        verbose_name_plural = "Pedidos"
        ordering = ["-criado_em"]

    def __str__(self):
        return f"Pedido #{self.pk} - {self.cliente}"

    def total_pedido(self):
        """
        Calcula o valor total do pedido.

        O total considera a quantidade de cada item multiplicada
        pelo preço registrado no momento da compra.
        """
        total = Decimal("0.00")

        for item in self.itens.all():
            total += item.quantidade * item.preco_unitario

        return total


class ItemPedido(models.Model):
    """
    Representa um produto dentro de um pedido.

    O preço unitário é salvo no momento da compra para preservar
    o valor histórico, mesmo se o preço do produto mudar depois.
    """

    pedido = models.ForeignKey(
        to=Pedido,
        on_delete=models.CASCADE,
        related_name="itens",
        verbose_name="Pedido",
    )

    produto = models.ForeignKey(
        to=Produto,
        on_delete=models.PROTECT,
        related_name="itens_pedido",
        verbose_name="Produto",
    )

    quantidade = models.PositiveIntegerField(
        default=1,
        verbose_name="Quantidade",
    )

    preco_unitario = models.DecimalField(
        max_digits=10,
        decimal_places=2,
        verbose_name="Preço unitário",
    )

    class Meta:
        verbose_name = "Item do pedido"
        verbose_name_plural = "Itens do pedido"
        ordering = ["pedido", "produto"]

    def __str__(self):
        return f"{self.quantidade}x {self.produto.nome}"

    def subtotal(self):
        """
        Retorna o valor total do item.
        """
        return self.quantidade * self.preco_unitario


class ComentarioAvaliacao(models.Model):
    """
    Avaliação e comentário de um cliente sobre um produto.
    """

    cliente = models.ForeignKey(
        to=Cliente,
        on_delete=models.CASCADE,
        related_name="avaliacoes",
        verbose_name="Cliente",
    )

    produto = models.ForeignKey(
        to=Produto,
        on_delete=models.CASCADE,
        related_name="avaliacoes",
        verbose_name="Produto",
    )

    texto = models.TextField(
        verbose_name="Comentário",
    )

    nota = models.PositiveSmallIntegerField(
        # Valores permitidos: 1, 2, 3, 4 e 5.
        choices=[(nota, str(nota)) for nota in range(1, 6)],
        verbose_name="Nota",
    )

    criado_em = models.DateTimeField(
        auto_now_add=True,
        verbose_name="Criado em",
    )

    class Meta:
        verbose_name = "Comentário e avaliação"
        verbose_name_plural = "Comentários e avaliações"
        ordering = ["-criado_em"]

    def __str__(self):
        return f"{self.produto.nome} - nota {self.nota}"
```

### 🔍 2.1. Campos importantes

| Campo | Para que serve | Quando usar |
|---|---|---|
| `CharField` | Texto curto, como nome, telefone e CEP | Sempre que houver limite de caracteres |
| `TextField` | Texto longo, como descrição e comentário | Quando o texto pode ser extenso |
| `DecimalField` | Números decimais precisos | Preços, valores financeiros e medidas |
| `PositiveIntegerField` | Número inteiro igual ou maior que zero | Estoque e quantidade |
| `DateField` | Data, sem hora | Data de nascimento |
| `DateTimeField` | Data e hora | Registro de criação ou atualização |
| `ImageField` | Upload e referência a imagem | Foto de perfil |
| `ForeignKey` | Relação muitos-para-um | Produto → Categoria; Pedido → Cliente |
| `OneToOneField` | Relação um-para-um | Cliente → User |
| `TextChoices` | Lista fixa de opções | Status, sexo e notas |

### 🔍 2.2. Parâmetros essenciais

| Parâmetro | Função |
|---|---|
| `max_length` | Define o limite máximo de caracteres |
| `unique=True` | Impede valores repetidos |
| `blank=True` | Permite campo vazio em formulários |
| `null=True` | Permite `NULL` no banco de dados |
| `default` | Define um valor inicial |
| `choices` | Restringe os valores aceitos |
| `verbose_name` | Define o rótulo legível no Admin |
| `related_name` | Define o nome para acessar objetos relacionados |
| `on_delete` | Define o comportamento quando o objeto relacionado é excluído |
| `auto_now_add=True` | Salva data/hora apenas na criação |
| `auto_now=True` | Atualiza data/hora a cada salvamento |

### ⚠️ 2.3. `on_delete`: escolha consciente

| Opção | Comportamento | Uso recomendado |
|---|---|---|
| `CASCADE` | Exclui também os objetos relacionados | Dados dependentes, como itens de um pedido |
| `PROTECT` | Impede a exclusão se houver registros vinculados | Produtos já vendidos, endereços usados em pedidos |
| `SET_NULL` | Define o campo como `NULL` | Relação opcional |
| `SET_DEFAULT` | Define um valor padrão | Relação com fallback previsível |
| `DO_NOTHING` | Não faz nada; pode causar erro no banco | Raramente recomendado |

No código, `Produto.categoria` usa `CASCADE` porque, sem categoria, o produto perde sua classificação. Já `Pedido.endereco_entrega` usa `PROTECT`, pois excluir um endereço não deve apagar ou corromper o histórico de pedidos.

## 🔄 3. Migrações

Os *`models`* definem a estrutura em Python. As `migrações` traduzem essa estrutura para alterações no banco de dados.

```bash
# Cria os arquivos de migração com base nos models
python manage.py makemigrations

# Aplica as migrações ao banco de dados
python manage.py migrate
```

Você verá uma saída semelhante a esta:

```text
Migrations for 'produtos':
  produtos\migrations\0001_initial.py
    + Create model Categoria
    + Create model Produto
    + Create model Cliente
    + Create model EnderecoEntrega
    + Create model Pedido
    + Create model ItemPedido
    + Create model ComentarioAvaliacao
```

> ---
> 💡 **Boa prática:** 
> 
> - Rode `makemigrations` sempre que alterar um model e `migrate` para aplicar as alterações. 
> - Não edite manualmente arquivos antigos de migração.
> 
> ---

## 🛠️ 4. Registrando no Admin

O Django Admin permite `criar`, `editar`, `filtrar` e `pesquisar` registros sem escrever telas administrativas do zero. Basta registrar os models; o Django gera automaticamente formulários e listagens. 

Crie ou substitua `produtos/admin.py`:

```python
# produtos/admin.py

from django.contrib import admin

from .models import (
    Categoria,
    Cliente,
    ComentarioAvaliacao,
    EnderecoEntrega,
    ItemPedido,
    Pedido,
    Produto,
)


@admin.register(Categoria)
class CategoriaAdmin(admin.ModelAdmin):
    """
    Configuração do painel administrativo para Categoria.
    """

    # Colunas exibidas na listagem.
    list_display = ["id", "nome", "descricao"]

    # Campos pesquisáveis na caixa de busca.
    search_fields = ["nome", "descricao"]

    # Ordenação padrão da listagem.
    ordering = ["nome"]


@admin.register(Produto)
class ProdutoAdmin(admin.ModelAdmin):
    """
    Configuração do painel administrativo para Produto.
    """

    list_display = [
        "id",
        "nome",
        "categoria",
        "preco",
        "quantidade_estoque",
        "criado_em",
    ]

    # Filtros laterais no Admin.
    list_filter = ["categoria", "criado_em"]

    # Permite pesquisar por nome do produto e nome da categoria.
    # O duplo underscore atravessa relacionamentos.
    search_fields = ["nome", "categoria__nome"]

    # Campos que não podem ser alterados manualmente.
    readonly_fields = ["criado_em", "atualizado_em"]


@admin.register(Cliente)
class ClienteAdmin(admin.ModelAdmin):
    """
    Configuração do painel administrativo para Cliente.
    """

    list_display = [
        "id",
        "usuario",
        "telefone",
        "sexo",
        "cpf",
    ]

    search_fields = [
        "usuario__username",
        "usuario__first_name",
        "usuario__last_name",
        "cpf",
    ]

    list_filter = ["sexo"]


@admin.register(EnderecoEntrega)
class EnderecoEntregaAdmin(admin.ModelAdmin):
    """
    Configuração do painel administrativo para Endereço de entrega.
    """

    list_display = [
        "id",
        "cliente",
        "logradouro",
        "numero",
        "cidade",
        "estado",
        "cep",
    ]

    search_fields = [
        "cliente__usuario__username",
        "cidade",
        "cep",
    ]

    list_filter = ["estado", "cidade"]


class ItemPedidoInline(admin.TabularInline):
    """
    Exibe e permite cadastrar itens dentro da página do Pedido.

    TabularInline mostra os itens em formato de tabela.
    """

    model = ItemPedido
    extra = 1  # Quantidade de linhas extras exibidas para novos itens


@admin.register(Pedido)
class PedidoAdmin(admin.ModelAdmin):
    """
    Configuração do painel administrativo para Pedido.
    """

    list_display = [
        "id",
        "cliente",
        "status",
        "endereco_entrega",
        "criado_em",
        "total_pedido",
    ]

    list_filter = ["status", "criado_em"]

    search_fields = [
        "cliente__usuario__username",
        "cliente__usuario__first_name",
        "cliente__usuario__last_name",
    ]

    # Exibe os itens diretamente na tela de edição do pedido.
    inlines = [ItemPedidoInline]

    readonly_fields = ["criado_em", "atualizado_em"]


@admin.register(ComentarioAvaliacao)
class ComentarioAvaliacaoAdmin(admin.ModelAdmin):
    """
    Configuração do painel administrativo para avaliações.
    """

    list_display = [
        "id",
        "produto",
        "cliente",
        "nota",
        "criado_em",
    ]

    list_filter = ["nota", "criado_em"]

    search_fields = [
        "produto__nome",
        "cliente__usuario__username",
        "texto",
    ]


# Registro simples, útil quando não há personalização necessária.
# admin.site.register(ItemPedido)
```

## 🧮 6. Desafio extra: `total_pedido`

O método `total_pedido()` já está implementado no model `Pedido`. Ele percorre todos os itens vinculados ao pedido e soma `quantidade * preco_unitario`.

```python
def total_pedido(self):
    """
    Calcula o valor total do pedido.

    Retorna um Decimal, garantindo precisão monetária.
    """
    total = Decimal("0.00")

    for item in self.itens.all():
        total += item.quantidade * item.preco_unitario

    return total
```

Exemplo de uso no Django shell:

```bash
python manage.py shell
```

```python
from produtos.models import Pedido

# Busca um pedido pelo ID 1
pedido = Pedido.objects.get(id=1)

# Exibe o total calculado
print(pedido.total_pedido())
```

Também é possível usar uma versão mais concisa:

```python
def total_pedido(self):
    """
    Calcula o total do pedido usando uma expressão geradora.
    """
    return sum(
        (item.quantidade * item.preco_unitario for item in self.itens.all()),
        Decimal("0.00"),
    )
```

## 🌐 8. View e rota

Crie ou substitua `produtos/views.py`:

```python
# produtos/views.py

from django.shortcuts import render

from .models import Produto


def lista_produtos(request):
    """
    Exibe a lista de produtos disponíveis.

    select_related("categoria") carrega a categoria junto com o produto,
    evitando consultas extras ao banco de dados dentro do template.
    """
    produtos = Produto.objects.select_related("categoria").all()

    contexto = {
        "produtos": produtos,
    }

    # render() combina a requisição, o template e os dados.
    return render(
        request,
        "produtos/produtos.html",
        contexto,
    )
```

Crie ou substitua `produtos/urls.py`:

```python
# produtos/urls.py

from django.urls import path

from . import views

# app_name evita conflitos entre nomes de URLs de aplicativos diferentes.
app_name = "produtos"

urlpatterns = [
    path(
        route="",
        view=views.lista_produtos,
        name="lista_produtos",
    ),
]
```

Atualize `config/urls.py`:

```python
# config/urls.py

from django.contrib import admin

    path("produtos/", include("produtos.urls")),
]
```
