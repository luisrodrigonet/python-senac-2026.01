## :one: Persistência de Dados em Arquivos Simples

**Persistência** de dados é a capacidade de um sistema de armazenar dados de forma permanente, mesmo após a execução do programa ser finalizada. **Arquivos simples** são uma das formas mais diretas e acessíveis de fazer isso. Eles são ideais para **pequenas aplicações, configurações, logs** ou para a troca de dados entre sistemas.

### 📂 Abrindo e Fechando Arquivos

Antes de qualquer operação, é preciso **abrir** o arquivo. Depois de manipular os dados, é fundamental **fechar** o arquivo para liberar os recursos do sistema.

A forma mais recomendada de trabalhar com arquivos é usando o gerenciador de contexto `with open(...)`, que garante que o arquivo será fechado automaticamente, mesmo se ocorrer um erro.

🐍 **Sintaxe básica**

```python
# Abre o arquivo para escrita ('w')
with open('exemplo.txt', 'w') as arquivo:
    # O objeto 'arquivo' está disponível aqui
    # Todas as operações de escrita são feitas dentro deste bloco

# O arquivo é fechado automaticamente aqui, mesmo que ocorra um erro.
```

📤 **Modos de Abertura**

O segundo argumento da função `open()` é o **modo de abertura**. Aqui estão os mais comuns:

  * `'r'` (**read**): Abre o arquivo para **leitura**. É o modo padrão. O arquivo deve existir, caso contrário, um erro será gerado.
 
  * `'w'` (**write**): Abre o arquivo para **escrita**. **Se o arquivo já existir, seu conteúdo será apagado.** Se não existir, um novo arquivo será criado.

  * `'a'` (**append**): Abre o arquivo para **adicionar conteúdo no final**. Se o arquivo não existir, um novo será criado. O conteúdo existente é preservado.

  * `'x'` (**exclusive creation**): Cria um **novo arquivo para escrita**. Se o arquivo já existir, um erro será gerado.

  * `'t'` (**text**): Modo **texto**. É o padrão. Os dados são manipulados como strings.

  * `'b'` (**binary**): Modo **binário**. Os dados são manipulados como bytes.

Você pode combinar os modos, como `'wb'` para escrita binária, ou `'at'` para adicionar em modo texto.


## :two: Manipulando Diferentes Formatos de Arquivo

Vamos agora explorar como trabalhar com os formatos de arquivo mais comuns: `TXT`, `CSV` e `JSON`.

### 2.1 Arquivos de Texto Simples (TXT)

Arquivos `.txt` são a forma mais básica de armazenar dados. Cada linha geralmente representa um registro ou uma informação. Eles são fáceis de ler e escrever.

#### Escrita em Arquivos TXT

Para escrever uma ou mais linhas em um arquivo de texto, você pode usar os métodos `write()` ou `writelines()`.

🐍 **Exemplo de Escrita:**

```python
dados = [
    "Maçã:10\n",
    "Banana:5\n",
    "Laranja:15\n"
]

with open('estoque.txt', 'w') as arquivo:
    # Escreve uma única linha
    arquivo.write("Lista de frutas:\n")

    # Escreve várias linhas de uma lista de strings
    arquivo.writelines(dados)

print("Arquivo estoque.txt criado com sucesso!")
```

 🚨 **Observação:**  Note que `writelines()` não adiciona quebras de linha (`\n`) automaticamente. Você precisa incluí-las na string, se necessário.

#### Leitura de Arquivos TXT

Para ler o conteúdo de um arquivo, use os métodos `read()`, `readline()` ou `readlines()`. O método mais comum é iterar sobre o objeto arquivo, o que lê o arquivo linha por linha de forma eficiente.

🐍 **Exemplo de Leitura:**

```python
try:
    with open('estoque.txt', 'r') as arquivo:
        print("Conteúdo do arquivo estoque.txt:")

        # Lê o arquivo linha por linha de forma eficiente
        for linha in arquivo:
            # strip() remove espaços em branco e a quebra de linha (\n)
            print(f"- {linha.strip()}")

except FileNotFoundError:
    print("Erro: O arquivo não foi encontrado.")
```

🚨 **Observação:** O uso de `try...except` é uma boa prática para lidar com a possibilidade de o arquivo não existir.


### 2.2 Arquivos de Valores Separados por Vírgula (CSV)

Arquivos `.csv` (Comma-Separated Values) são ideais para dados tabulares, como planilhas. Cada linha é um registro e os campos (colunas) são separados por um delimitador, geralmente uma vírgula. O Python oferece o módulo `csv` para simplificar a manipulação desses arquivos.

#### Vantagens do CSV:

  * Fácil de entender e abrir em programas como Excel ou Google Sheets.
  * Compacto e eficiente para dados tabulares.

#### Escrita em Arquivos CSV

Para escrever, usamos a função `csv.writer`. Ela cuida da formatação dos dados (adicionando vírgulas e aspas quando necessário).

🐍 **Exemplo de Escrita:**

```python
import csv

dados_usuarios = [
    ['id', 'nome', 'email'],
    [1, 'Alice', 'alice@email.com'],
    [2, 'Bob', 'bob@email.com'],
    [3, 'Carlos', 'carlos@email.com']
]

with open('usuarios.csv', 'w', newline='', encoding='utf-8') as arquivo_csv:
    # Cria o objeto escritor
    escritor = csv.writer(arquivo_csv)

    # Escreve todas as linhas de uma vez
    escritor.writerows(dados_usuarios)

print("Arquivo usuarios.csv criado com sucesso!")
```

🚨 **Observação:** O parâmetro `newline=''` é fundamental para evitar a criação de linhas em branco extras no arquivo CSV. O `encoding='utf-8'` é importante para garantir que caracteres especiais (como acentos) sejam salvos corretamente.

#### Leitura de Arquivos CSV

Para ler, usamos a função `csv.reader` ou `csv.DictReader` (que é ainda mais útil, pois lê cada linha como um dicionário).

🐍 **Exemplo de Leitura com `csv.DictReader`:**

```python
import csv

try:
    with open('usuarios.csv', 'r', encoding='utf-8') as arquivo_csv:
        # Cria o objeto leitor, que interpreta a primeira linha como cabeçalho
        leitor = csv.DictReader(arquivo_csv)
        print("Dados dos usuários:")

        for linha in leitor:
            # Cada linha é um dicionário onde a chave é o nome da coluna
            print(f"ID: {linha['id']}, Nome: {linha['nome']}, Email: {linha['email']}")

except FileNotFoundError:
    print("Erro: O arquivo não foi encontrado.")
```

🚨 **Observação:** O `DictReader` é excelente porque você acessa os dados por nome, em vez de índice, o que torna o código mais legível e menos propenso a erros.


### 2.3 Arquivos JSON (JavaScript Object Notation)

**`JSON`** é um formato de texto leve e legível por humanos, usado para representar dados estruturados. É amplamente utilizado na web para a comunicação entre cliente e servidor, mas também é perfeito para persistir dados complexos, como dicionários e listas aninhadas. O Python tem o módulo `json` embutido para lidar com esse formato.

#### Vantagens do JSON:

  * Estrutura hierárquica clara (dicionários, listas, etc.).
  * Amplamente utilizado e suportado em diversas linguagens.

#### Escrita em Arquivos JSON

Para escrever dados em um arquivo JSON, usamos a função `json.dump()`.

🐍 **Exemplo de Escrita:**

```python
import json

dados_produto = {
    'nome': 'Notebook Gamer',
    'marca': 'PythonTech',
    'preço': 7500.00,
    'em_estoque': True,
    'especificacoes': {
        'cpu': 'Intel Core i9',
        'ram_gb': 16,
        'ssd_gb': 1000
    },
    'tags': ['gamer', 'alto-desempenho']
}

with open('produto.json', 'w', encoding='utf-8') as arquivo_json:
    # json.dump() converte o dicionário Python para uma string JSON e salva no arquivo
    json.dump(dados_produto, arquivo_json, indent=4, ensure_ascii=False)

print("Arquivo produto.json criado com sucesso!")
```

🚨 **Observação:** O parâmetro `indent=4` adiciona formatação e identação ao arquivo, tornando-o muito mais fácil de ler. O `ensure_ascii=False` garante que caracteres acentuados sejam salvos corretamente em português.

#### Leitura de Arquivos JSON

Para ler dados de um arquivo JSON, usamos a função `json.load()`. Ela converte a string JSON de volta para um objeto Python (como um dicionário ou uma lista).

🐍 **Exemplo de Leitura:**

```python
import json

try:
    with open('produto.json', 'r', encoding='utf-8') as arquivo_json:
        # json.load() converte a string JSON em um dicionário Python
        produto = json.load(arquivo_json)
        
        print("Dados do produto:")
        print(f"Nome: {produto['nome']}")
        print(f"Preço: R${produto['preço']:.2f}")
        print(f"CPU: {produto['especificacoes']['cpu']}")
        print(f"Tags: {', '.join(produto['tags'])}")

except FileNotFoundError:
    print("Erro: O arquivo não foi encontrado.")
```

## :three: Atualizando Dados em Arquivos

Atualizar dados em um arquivo simples exige uma abordagem de "**ler-modificar-escrever**". Você não pode simplesmente "**editar**" um pedaço de um arquivo. A forma mais segura é:

1.  **Ler** o conteúdo completo do arquivo para a memória (variável).
2.  **Modificar** os dados na memória.
3.  **Escrever** os dados modificados de volta no arquivo, sobrescrevendo o conteúdo original.

🐍 **Exemplo de Atualização de um JSON:**

Vamos supor que o preço do notebook mudou e precisamos atualizar o arquivo `produto.json`.

```python
import json

# 1. Ler o conteúdo
try:
    with open('produto.json', 'r', encoding='utf-8') as arquivo_json:
        dados = json.load(arquivo_json)

    # 2. Modificar os dados na memória
    dados['preço'] = 6999.00  # Novo preço
    dados['em_estoque'] = False # Produto esgotado

    # 3. Escrever os dados modificados de volta no arquivo
    with open('produto.json', 'w', encoding='utf-8') as arquivo_json:
        json.dump(dados, arquivo_json, indent=4, ensure_ascii=False)
    
    print("Arquivo produto.json atualizado com sucesso!")
    
except FileNotFoundError:
    print("Erro: O arquivo não foi encontrado.")
```

## :four: Conclusão e Recomendações

A escolha do formato de arquivo depende da sua necessidade:

  * Use **TXT** para dados simples, como logs ou listas de itens. É o mais fácil de implementar.
  * Use **CSV** para dados tabulares, como planilhas. O módulo `csv` torna o trabalho muito mais fácil e seguro.
  * Use **JSON** para dados estruturados e hierárquicos, como configurações ou informações complexas de objetos. O módulo `json` é a escolha ideal para serializar e deserializar objetos Python.
