# Desafio Prático Atualizado: Agenda de Contatos em Python com CSV

Você deve desenvolver um programa em Python que funcione como uma **Agenda de Contatos** simples. Todos os dados da agenda (os contatos) devem ser persistidos (salvos) em um arquivo no formato **CSV** (Comma Separated Values).

O programa deve ser estruturado em funções, seguindo boas práticas, e deve permitir as seguintes operações:

1.  **Adicionar Novo Contato:** Solicitar **nome**, **telefone** e **e-mail** do usuário e salvar o novo contato no arquivo CSV.
2.  **Listar Contatos:** Ler o arquivo CSV e **exibir todos** os contatos formatados de maneira clara.
3.  **Buscar Contato:** Permitir ao usuário **buscar** um contato pelo **nome** (ou parte dele) e exibir os detalhes encontrados.
4.  **Excluir Contato:** Permitir ao usuário **remover** um contato da agenda, buscando-o pelo nome (ou ID) e reescrevendo o arquivo CSV.

### Requisitos de Implementação:

1.  **Estrutura de Dados:** Cada contato deve ser um dicionário Python (ex: `{"nome": "...", "telefone": "...", "email": "..."}`). A lista completa de contatos deve ser uma lista de dicionários.
2.  **Nome do Arquivo:** O arquivo de dados deve se chamar `agenda.csv`.
3.  **Cabeçalho do CSV:** O arquivo CSV deve conter um cabeçalho (header) com os nomes dos campos: `nome`, `telefone`, `email`.
4.  **Função de Carregamento:** Crie uma função para *carregar* (ler) os dados do arquivo. Ela deve tratar o caso em que o arquivo **não existe** (criando uma lista vazia, se necessário).
5.  **Função de Salvamento:** Crie uma função para *salvar* (escrever) a lista completa de contatos no arquivo CSV.
6.  **Utilização do Módulo `csv`:** É obrigatório o uso do módulo embutido `csv` do Python (`import csv`).


## 🎯 Resolução do Exercício com CSV

### :one: Estrutura e Funções de Base (CSV)

Utilizaremos o módulo `csv` com o objeto `DictReader` para leitura e `DictWriter` para escrita, pois eles trabalham diretamente com dicionários (mantendo o formato de dados dos contatos).

```python
import csv
import os

# --- Configuração ---
ARQUIVO_AGENDA = "agenda.csv"
# O cabeçalho do nosso arquivo CSV
CAMPOS = ["nome", "telefone", "email"] 

# --- Funções de Base (Manipulação de Arquivo CSV) ---
"""
Carrega a lista de contatos do arquivo CSV.
Retorna uma lista vazia se o arquivo não existir.
"""
def carregar_contatos():

    if not os.path.exists(ARQUIVO_AGENDA):
        print(f"Arquivo '{ARQUIVO_AGENDA}' não encontrado. Criando nova agenda vazia.")
        return []

    try:
        # Abertura em modo 'r' (leitura)
        with open(ARQUIVO_AGENDA, 'r', newline='', encoding='utf-8') as f:
            
            # Observação 1: DictReader lê o CSV e retorna cada linha como um dicionário
            reader = csv.DictReader(f)
            
            # Converte o iterador do reader em uma lista de dicionários
            return list(reader)
            
    except Exception as e:
        print(f"Erro inesperado ao carregar contatos do CSV: {e}")
        return []

"""
Salva a lista completa de contatos no arquivo CSV, incluindo o cabeçalho.
"""
def salvar_contatos(contatos):

    try:
        # Abertura em modo 'w' (escrita/sobrescrita). 'newline=""' é essencial para CSV no Windows.
        with open(ARQUIVO_AGENDA, 'w', newline='', encoding='utf-8') as f:

            # Observação 2: DictWriter escreve dicionários no arquivo CSV
            writer = csv.DictWriter(f, fieldnames=CAMPOS)
            
            # Escreve o cabeçalho (campos definidos em CAMPOS)
            writer.writeheader()
            
            # Escreve todas as linhas de dados
            writer.writerows(contatos)
            
        print("\nAgenda salva com sucesso no formato CSV!")

    except Exception as e:
        print(f"\nERRO ao salvar a agenda no CSV: {e}")

```

**Observação** 
- Usamos 'newline=""' no open() ao lidar com o módulo 'csv'. Isso previne que linhas em branco indesejadas sejam adicionadas entre os registros no arquivo, um problema comum no tratamento de CSV em diferentes SOs.

### :two: Funções de Operação da Agenda


#### 2.1 Adicionar

```python
"""
Adiciona um novo contato à lista e salva no arquivo.
"""
def adicionar_contato(contatos):

    print("\n--- Adicionar Novo Contato ---")
    nome = input("Nome: ").strip()
    telefone = input("Telefone: ").strip()
    email = input("Email: ").strip()

    if not nome or not telefone:
        print("Nome e Telefone são campos obrigatórios. Operação cancelada.")
        return

    novo_contato = {
        "nome": nome,
        "telefone": telefone,
        "email": email
    }
    
    contatos.append(novo_contato)
    salvar_contatos(contatos)

```

#### 2.2 Listar

```python
"""
Exibe todos os contatos de forma formatada.
"""
def listar_contatos(contatos):

    print("\n--- Lista de Contatos ---")
    if not contatos:
        print("A agenda está vazia.")
        return

    for i, contato in enumerate(contatos):
        print("-" * 30)
        print(f"ID: {i+1}") 
        print(f"Nome: {contato.get('nome', 'N/A')}")
        print(f"Telefone: {contato.get('telefone', 'N/A')}")
        print(f"Email: {contato.get('email', 'N/A')}")
    print("-" * 30)
    print(f"Total de contatos: {len(contatos)}")
```

#### 2.3 Buscar

```python
"""
Busca contatos pelo nome (parcial ou completo) usando for loop explícito.
"""
def buscar_contato(contatos):

    if not contatos:
        print("A agenda está vazia. Nada para buscar.")
        return
        
    termo = input("\nDigite o nome (ou parte do nome) para buscar: ").strip().lower()
    
    # Substituição solicitada: For Loop Tradicional
    encontrados = []
    for c in contatos:
        # Acesso seguro à chave e conversão para minúsculas
        nome_contato = c.get('nome', '').lower() 
        if termo in nome_contato:
            encontrados.append(c)

    if not encontrados:
        print(f"Nenhum contato encontrado com o termo '{termo}'.")
        return

    print(f"\n--- Contatos Encontrados (Total: {len(encontrados)}) ---")
    for contato in encontrados:
        print(f"Nome: {contato['nome']}, Telefone: {contato['telefone']}")
    print("-" * 30)

```

#### 2.4 Excluir

```python
"""
Exclui um contato da lista pelo ID (índice) e reescreve o CSV.
"""    
def excluir_contato(contatos):

    listar_contatos(contatos) 
    if not contatos:
        return

    try:
        id_excluir = int(input("Digite o ID do contato a ser EXCLUÍDO (ou 0 para cancelar): "))
        
        if id_excluir == 0:
            print("Exclusão cancelada.")
            return

        indice = id_excluir - 1 

        if 0 <= indice < len(contatos):
            contato_removido = contatos.pop(indice) 
            salvar_contatos(contatos) # Chama a função de salvamento CSV
            print(f"Contato '{contato_removido['nome']}' removido com sucesso!")
        else:
            print("ID inválido. Por favor, digite um número da lista.")

    except ValueError:
        print("Entrada inválida. Digite um número.")
    except Exception as e:
        print(f"Erro ao tentar excluir: {e}")
```

### :three: Menu Principal e Execução

O bloco principal do programa que carrega a agenda e exibe o menu de opções.

```python
def menu_principal():
    """
    Exibe o menu de opções e controla o fluxo do programa.
    """
    agenda_contatos = carregar_contatos() 

    while True:
        print("\n*** Agenda de Contatos em CSV ***")
        print("1. Adicionar Contato")
        print("2. Listar Contatos")
        print("3. Buscar Contato")
        print("4. Excluir Contato")
        print("5. Sair")
        
        escolha = input("Escolha uma opção: ").strip()

        if escolha == '1':
            adicionar_contato(agenda_contatos)
        elif escolha == '2':
            listar_contatos(agenda_contatos)
        elif escolha == '3':
            buscar_contato(agenda_contatos)
        elif escolha == '4':
            excluir_contato(agenda_contatos)
        elif escolha == '5':
            print("Saindo da Agenda. Até logo!")
            break
        else:
            print("Opção inválida. Tente novamente.")

if __name__ == "__main__":
    menu_principal()
```
