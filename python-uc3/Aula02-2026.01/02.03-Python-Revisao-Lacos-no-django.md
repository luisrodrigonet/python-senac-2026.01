## 2. Laço `for`

No backend do Django (dentro de `views.py`), o laço `for` do Python é usado para preparar listas, calcular totais, filtrar dados e processar parâmetros recebidos. No frontend (templates), o Django possui uma sintaxe própria baseada em tags: `{% for item in lista %} ... {% endfor %}`.

### Exemplo Integrado: Lista e Tabuada

#### `loops_app/views.py`

```python
from django.shortcuts import render

def pagina_for(request):
    # 1. Iterando sobre listas e range no Python (Backend)
    frutas = ["Maçã", "Banana", "Cereja", "Morango"]
    
    # Recebe um número via GET (ex: ?numero=7) ou usa 5 como padrão
    numero = int(request.GET.get('numero', 5))
    
    tabuada = []
    for i in range(1, 11):
        tabuada.append({
            'multiplicador': i,
            'resultado': numero * i
        })

    contexto = {
        'frutas': frutas,
        'numero': numero,
        'tabuada': tabuada,
    }
    return render(request, 'loops_app/exemplo_for.html', contexto)

```

#### `loops_app/templates/loops_app/exemplo_for.html`

```html
<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="UTF-8">
    <title>Laço For no Django</title>
</head>
<body>
    <h1>Exemplos com Laço For</h1>

    <h2>1. Lista de Frutas</h2>
    <ul>
        {% for fruta in frutas %}
            <li>Eu gosto de {{ fruta }}.</li>
        {% empty %}
            <li>Nenhuma fruta encontrada.</li>
        {% endfor %}
    </ul>

    <h2>2. Tabuada Dinâmica do {{ numero }}</h2>
    <form method="get">
        <label>Alterar número: </label>
        <input type="number" name="numero" value="{{ numero }}">
        <button type="submit">Calcular</button>
    </form>

    <ul>
        {% for item in tabuada %}
            <li>{{ numero }} x {{ item.multiplicador }} = {{ item.resultado }}</li>
        {% endfor %}
    </ul>
</body>
</html>

```

## 3. Laço `while`

Diferente de scripts locais de console, na web um servidor HTTP funciona em ciclos de **Requisição e Resposta**.

* **Atenção:** Nunca use `input()` dentro de uma view do Django, pois travará a execução do servidor. A entrada do usuário deve vir de formulários (`request.GET` ou `request.POST`).


* **Cuidado com Loops Infinitos:** No servidor, um `while` sem critério de parada consome 100% da CPU e impede a página de carregar para o usuário.

### Exemplo Integrado: Jogo de Adivinhação com Sessão

O exercício do "Jogo de Adivinhação" (que dependia de palpites repetidos) em uma aplicação web é resolvido mantendo o estado na **sessão** (`request.session`) a cada requisição:

#### `loops_app/views.py`

```python
import random
from django.shortcuts import render

def jogo_adivinhacao(request):
    # Inicializa o segredo e contador na sessão do navegador
    if 'numero_secreto' not in request.session:
        request.session['numero_secreto'] = random.randint(1, 10)
        request.session['tentativas'] = 0

    mensagem = ""
    acertou = False

    if request.method == "POST":
        palpite = int(request.POST.get('palpite', 0))
        request.session['tentativas'] += 1
        segredo = request.session['numero_secreto']

        if palpite < segredo:
            mensagem = "O número secreto é maior!"
        elif palpite > segredo:
            mensagem = "O número secreto é menor!"
        else:
            mensagem = f"Parabéns! Você acertou em {request.session['tentativas']} tentativa(s)."
            acertou = True
            # Reinicia o jogo
            del request.session['numero_secreto']
            del request.session['tentativas']

    return render(request, 'loops_app/jogo.html', {'mensagem': mensagem, 'acertou': acertou})

```

#### `loops_app/templates/loops_app/jogo.html`

```html
<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="UTF-8">
    <title>Jogo de Adivinhação</title>
</head>
<body>
    <h1>Jogo de Adivinhação (1 a 10)</h1>
    
    {% if mensagem %}
        <p><strong>{{ mensagem }}</strong></p>
    {% endif %}

    {% if not acertou %}
        <form method="post">
            {% csrf_token %}
            <label>Qual é o seu palpite? </label>
            <input type="number" name="palpite" min="1" max="10" required>
            <button type="submit">Enviar Palpite</button>
        </form>
    {% else %}
        <a href="">Jogar Novamente</a>
    {% endif %}
</body>
</html>

```

## 4. Configuração das Rotas (URLs)

Para testar as duas páginas no navegador:

#### `loops_app/urls.py`

```python
from django.urls import path
from . import views

urlpatterns = [
    path('for/', views.pagina_for, name='pagina_for'),
    path('jogo/', views.jogo_adivinhacao, name='jogo_adivinhacao'),
]

```

#### `meu_projeto/urls.py`

```python
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('', include('loops_app.urls')),
]

```
