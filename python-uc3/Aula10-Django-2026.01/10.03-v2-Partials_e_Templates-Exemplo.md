# 10.03v2 Templates em Django 5.2 - Criando uma Aplicação Blog

## :one: Conceito de Templates e Aplicação no Django

### 1.1. O que são Templates?

Templates no `Django` são arquivos que contêm o código HTML da sua aplicação, combinados com a **Template Language do Django** (`DLT`) - uma linguagem especial que permite inserir dados dinâmicos do Python diretamente no HTML.

Enquanto as **Models** representam os dados e as **Views** contêm a lógica de negócios, os templates formam a **camada de apresentação**, responsável por como os dados são exibidos ao usuário.

### 1.2 Por que usar Templates?

🚇 **Separação de Responsabilidades:** Mantém o código HTML separado da lógica Python, facilitando manutenção e colaboração entre desenvolvedores.

🚇**Reutilização de Código:** Templates podem ser herdados e estendidos, evitando duplicação.

🚇**Lógica de Apresentação Simples:** A Template Language do Django permite loops, condicionais e filtros sem necessidade de JavaScript complexo.

🚇 **Segurança:** O Django automaticamente escapa caracteres perigosos em templates, prevenindo ataques XSS (Cross-Site Scripting).

### 1.3 Arquitetura Templates no Django

```
┌─────────────────────────────────────────────┐
│         Cliente (Navegador)                 │
└────────────────┬────────────────────────────┘
                 │ HTTP Request
                 ▼
┌─────────────────────────────────────────────┐
│      URLs (urls.py) - Roteamento            │
└────────────────┬────────────────────────────┘
                 │ Encontra a View apropriada
                 ▼
┌─────────────────────────────────────────────┐
│      Views (views.py) - Lógica              │
│  • Busca dados das Models                   │
│  • Processa requisições                     │
│  • Passa dados para o Template              │
└────────────────┬────────────────────────────┘
                 │ Context (dados)
                 ▼
┌─────────────────────────────────────────────┐
│    Templates (*.html) - Apresentação        │
│  • Recebe dados do Context                  │
│  • Renderiza HTML dinâmico                  │
│  • Template Language do Django              │
└────────────────┬────────────────────────────┘
                 │ HTML Renderizado
                 ▼
┌─────────────────────────────────────────────┐
│      Cliente (Navegador)                    │
└─────────────────────────────────────────────┘
```

## :two: Criação da Aplicação "Blog"

Antes de criar templates, você precisa criar a aplicação Django. Assumindo que já tem um projeto Django criado, siga estes passos:

### Passo 1: Criar a Aplicação Blog

```bash
# Navegue até a pasta do seu projeto
cd seu_projeto_django

# Crie a aplicação blog
python manage.py startapp blog

```

### Passo 4: Configurar Templates no Settings

O Django precisa saber onde procurar pelos templates. Abra novamente `seu_projeto/settings.py` e configure:

```python
# seu_projeto/settings.py
import os
from pathlib import Path

BASE_DIR = Path(__file__).resolve().parent.parent

TEMPLATES = [
    {
        'BACKEND': 'django.template.backends.django.DjangoTemplates',
        'DIRS': [BASE_DIR / 'templates'], # <-- Onde buscar templates do projeto
        'APP_DIRS': True,                 # <-- Busca templates dentro de cada app
        'OPTIONS': {
            'context_processors': [
                'django.template.context_processors.debug',
                'django.template.context_processors.request',
                'django.contrib.auth.context_processors.auth',
                'django.contrib.messages.context_processors.messages',
            ],
        },
    },
]

# Configuração de arquivos estáticos
STATIC_URL = '/static/'
STATICFILES_DIRS = [os.path.join(BASE_DIR, 'static')]
STATIC_ROOT = os.path.join(BASE_DIR, 'staticfiles')

# Configuração dos arquivos Media - necessários para o banco de dados
MEDIA_URL = 'media/'
MEDIA_ROOT = BASE_DIR / "media"
```

### 4.2. Criando os Models

Abra `blog/models.py` e defina os três models principais:

```python
# blog/models.py
from django.db import models
from django.contrib.auth.models import User
from django.urls import reverse
from django.utils.text import slugify

class Categoria(models.Model):
    """
    Model para representar categorias de posts.
    Um post pode pertencer a apenas uma categoria,
    mas uma categoria pode ter vários posts.
    """
    nome = models.CharField(
        max_length=100, 
        unique=True,
        help_text="Nome único da categoria"
    )
    slug = models.SlugField(
        max_length=100, 
        unique=True, 
        blank=True,
        help_text="URL amigável para a categoria (gerado automaticamente)"
    )
    descricao = models.TextField(
        blank=True,
        help_text="Descrição detalhada da categoria"
    )
    criado_em = models.DateTimeField(auto_now_add=True)
    
    class Meta:
        verbose_name = 'Categoria'
        verbose_name_plural = 'Categorias'
        ordering = ['nome']
    
    def __str__(self):
        """Retorna o nome da categoria quando convertida em string"""
        return self.nome
    
    def save(self, *args, **kwargs):
        """
        Sobrescreve o método save para gerar slug automaticamente
        se não for fornecido
        """
        if not self.slug:
            self.slug = slugify(self.nome)
        super().save(*args, **kwargs)
    
    def get_absolute_url(self):
        """Retorna a URL da categoria"""
        return reverse('posts_por_categoria', args=[self.slug])


class Post(models.Model):
    """
    Model para representar posts/artigos do blog.
    Cada post tem um autor (usuário), uma categoria,
    um título, conteúdo, e pode ter múltiplos comentários.
    """
    STATUS_CHOICES = (
        ('rascunho', 'Rascunho'),
        ('publicado', 'Publicado'),
    )
    
    titulo = models.CharField(
        max_length=200,
        help_text="Título do post (máximo 200 caracteres)"
    )
    slug = models.SlugField(
        max_length=200, 
        unique=True, 
        blank=True,
        help_text="URL amigável do post (gerado automaticamente)"
    )
    autor = models.ForeignKey(
        User, 
        on_delete=models.CASCADE,
        related_name='posts',
        help_text="Autor do post (usuário do Django)"
    )
    categoria = models.ForeignKey(
        Categoria, 
        on_delete=models.SET_NULL, 
        null=True,
        related_name='posts',
        help_text="Categoria do post"
    )
    conteudo = models.TextField(
        help_text="Conteúdo completo do post (suporta HTML básico)"
    )
    resumo = models.TextField(
        max_length=300, 
        blank=True,
        help_text="Resumo curto do post (exibido em cards)"
    )
    imagem_destaque = models.ImageField(
        upload_to='posts/%Y/%m/%d/', 
        blank=True,
        help_text="Imagem de destaque do post"
    )
    status = models.CharField(
        max_length=10, 
        choices=STATUS_CHOICES, 
        default='rascunho',
        help_text="Status de publicação do post"
    )
    criado_em = models.DateTimeField(auto_now_add=True)
    atualizado_em = models.DateTimeField(auto_now=True)
    publicado_em = models.DateTimeField(
        null=True, 
        blank=True,
        help_text="Data de publicação (null = não publicado)"
    )
    visualizacoes = models.PositiveIntegerField(
        default=0,
        help_text="Contador de visualizações"
    )
    
    class Meta:
        verbose_name = 'Post'
        verbose_name_plural = 'Posts'
        ordering = ['-publicado_em', '-criado_em']
    
    def __str__(self):
        """Retorna o título do post"""
        return self.titulo
    
    def save(self, *args, **kwargs):
        """
        Sobrescreve o método save para gerar slug automaticamente
        """
        if not self.slug:
            self.slug = slugify(self.titulo)
        super().save(*args, **kwargs)
    
    def get_absolute_url(self):
        """Retorna a URL do post (para usar em templates)"""
        return reverse('post_detail', args=[self.slug])


class Comentario(models.Model):
    """
    Model para representar comentários em posts.
    Cada comentário pertence a um post e é feito por um usuário.
    """
    post = models.ForeignKey(
        Post, 
        on_delete=models.CASCADE,
        related_name='comentarios',
        help_text="Post ao qual o comentário pertence"
    )
    autor = models.ForeignKey(
        User, 
        on_delete=models.CASCADE,
        related_name='comentarios',
        help_text="Autor do comentário"
    )
    conteudo = models.TextField(
        help_text="Conteúdo do comentário"
    )
    criado_em = models.DateTimeField(auto_now_add=True)
    atualizado_em = models.DateTimeField(auto_now=True)
    ativo = models.BooleanField(
        default=True,
        help_text="Se falso, comentário não será exibido"
    )
    
    class Meta:
        verbose_name = 'Comentário'
        verbose_name_plural = 'Comentários'
        ordering = ['-criado_em']
    
    def __str__(self):
        """Retorna uma descrição do comentário"""
        return f'Comentário de {self.autor.username} em "{self.post.titulo}"'
```

### 5.2. Registro Customizado (Recomendado)

Para uma melhor experiência, você pode customizar como os `models` aparecem no admin:

```python
# blog/admin.py
from django.contrib import admin
from django.utils.html import format_html
from .models import Categoria, Post, Comentario


@admin.register(Categoria)
class CategoriaAdmin(admin.ModelAdmin):
    """
    Customiza como a Categoria aparece no admin.
    O decorador @admin.register é uma forma alternativa 
    de registrar modelos.
    """
    list_display = ('nome', 'quantidade_posts', 'criado_em')
    list_filter = ('criado_em',)
    search_fields = ('nome', 'descricao')
    readonly_fields = ('slug', 'criado_em')
    prepopulated_fields = {'slug': ('nome',)}
    
    def quantidade_posts(self, obj):
        """Método customizado para mostrar contagem de posts"""
        return obj.posts.count()
    quantidade_posts.short_description = 'Quantidade de Posts'


@admin.register(Post)
class PostAdmin(admin.ModelAdmin):
    """
    Customiza como o Post aparece no admin com fields bem organizados.
    """
    list_display = ('titulo', 'autor', 'categoria', 'status', 
                    'publicado_em', 'visualizacoes', 'comentarios_count')
    list_filter = ('status', 'categoria', 'criado_em', 'publicado_em')
    search_fields = ('titulo', 'conteudo', 'autor__username')
    readonly_fields = ('slug', 'criado_em', 'atualizado_em', 'visualizacoes')
    prepopulated_fields = {'slug': ('titulo',)}
    
    # Organiza os fields em abas/seções
    fieldsets = (
        ('Informações Básicas', {
            'fields': ('titulo', 'slug', 'autor', 'categoria')
        }),
        ('Conteúdo', {
            'fields': ('resumo', 'conteudo', 'imagem_destaque'),
            'classes': ('wide',)
        }),
        ('Publicação', {
            'fields': ('status', 'publicado_em'),
            'classes': ('collapse',)
        }),
        ('Estatísticas', {
            'fields': ('visualizacoes', 'criado_em', 'atualizado_em'),
            'classes': ('collapse',)
        }),
    )
    
    def comentarios_count(self, obj):
        """Mostra contagem de comentários"""
        count = obj.comentarios.filter(ativo=True).count()
        return format_html(
            '<span style="background-color: #17a2b8; color: white; '
            'padding: 3px 8px; border-radius: 3px;">{}</span>',
            count
        )
    comentarios_count.short_description = 'Comentários'


@admin.register(Comentario)
class ComentarioAdmin(admin.ModelAdmin):
    """
    Customiza como o Comentário aparece no admin.
    """
    list_display = ('autor', 'post', 'criado_em', 'ativo', 'preview_conteudo')
    list_filter = ('ativo', 'criado_em', 'post')
    search_fields = ('autor__username', 'post__titulo', 'conteudo')
    readonly_fields = ('criado_em', 'atualizado_em')
    list_editable = ('ativo',)  # Permite editar diretamente na listagem
    
    def preview_conteudo(self, obj):
        """Mostra preview do comentário"""
        preview = obj.conteudo[:50]
        return f"{preview}..." if len(obj.conteudo) > 50 else preview
    preview_conteudo.short_description = 'Conteúdo (Preview)'
```

📢 **Explicação das Customizações:**

- **`list_display`**: Define quais campos aparecem na listagem
- **`list_filter`**: Adiciona filtros na lateral direita
- **`search_fields`**: Permite buscar por esses campos
- **`readonly_fields`**: Campos que não podem ser editados
- **`prepopulated_fields`**: Campos preenchidos automaticamente (slug)
- **`fieldsets`**: Organiza os campos em seções
- **`@admin.register`**: Decorador alternativo para registrar modelos

## 8. Criação das Views 

As `Views` são **funções** ou **classes** que processam requisições `HTTP` e retornam respostas. Para templates dinâmicos, usamos **Class-Based Views** que facilitam operações comuns como listagem e detalhamento.

### 8.1 Criando as Views Principais

Abra `blog/views.py`:

```python
# blog/views.py
from django.views.generic import ListView, DetailView       # <-- Class-Based Views Genéricas
from django.shortcuts import get_object_or_404, redirect    # <-- Redirecionamento e msg de erro 
                                                            #       qd nao localiza um objeto
from django.contrib.auth.decorators import login_required   # <-- controle de acesso
from django.db.models import Count, Q
from django.utils import timezone
from .models import Post, Categoria, Comentario             # <-- Classes criadas no model  que 
                                                            #     fornecerão os dados


class PostListView(ListView):
    """
    View para listar todos os posts publicados com paginação.
    
    Attributes:
        model: O model a ser listado (Post)
        template_name: Nome do template a renderizar
        context_object_name: Nome da variável no template (posts)
        paginate_by: Quantidade de posts por página
    """
    model = Post
    template_name = 'blog/post_list.html'
    context_object_name = 'posts'
    paginate_by = 9  # 9 posts por página (3x3 grid com Bootstrap)
    
    def get_queryset(self):
        """
        Retorna posts filtrados.
        
        - Apenas posts com status 'publicado'
        - select_related otimiza queries (reduz consultas ao banco)
        - Aceita parâmetro 'q' para busca
        """
        queryset = Post.objects.filter(
            status='publicado'
        ).select_related('autor', 'categoria')
        
        # Busca por query string
        query = self.request.GET.get('q')
        if query:
            queryset = queryset.filter(
                Q(titulo__icontains=query) | 
                Q(conteudo__icontains=query) |
                Q(resumo__icontains=query)
            )
        
        return queryset
    
    def get_context_data(self, **kwargs):
        """
        Adiciona dados extras ao contexto que será passado ao template.
        """
        context = super().get_context_data(**kwargs)
        
        # Categorias com contagem de posts
        context['categorias'] = Categoria.objects.annotate(
            num_posts=Count('posts', filter=Q(posts__status='publicado'))
        )
        
        # Posts recentes para o sidebar
        context['posts_recentes'] = Post.objects.filter(
            status='publicado'
        ).order_by('-publicado_em')[:5]
        
        # Tags populares (exemplo fixo - em produção vem do banco)
        context['tags_populares'] = ['Django', 'Python', 'Web', 'Bootstrap']
        
        return context


class PostDetailView(DetailView):
    """
    View para exibir os detalhes completos de um post específico.
    
    - Usa slug como parâmetro de URL
    - Incrementa contador de visualizações
    - Mostra comentários relacionados
    """
    model = Post
    template_name = 'blog/post_detail.html'
    context_object_name = 'post'
    slug_field = 'slug'  # Campo usado para buscar
    slug_url_kwarg = 'slug'  # Nome do parâmetro na URL
    
    def get_queryset(self):
        """
        Retorna apenas posts publicados.
        """
        return Post.objects.filter(
            status='publicado'
        ).select_related('autor', 'categoria')
    
    def get_object(self, queryset=None):
        """
        Sobrescreve para incrementar contador de visualizações.
        """
        obj = super().get_object(queryset)
        obj.visualizacoes += 1
        obj.save(update_fields=['visualizacoes'])
        return obj
    
    def get_context_data(self, **kwargs):
        """
        Adiciona comentários e posts relacionados ao contexto.
        """
        context = super().get_context_data(**kwargs)
        post = self.object
        
        # Comentários do post (apenas os ativos)
        context['comentarios'] = post.comentarios.filter(
            ativo=True
        ).select_related('autor')
        
        # Posts relacionados (mesma categoria, excluindo este)
        context['posts_relacionados'] = Post.objects.filter(
            categoria=post.categoria,
            status='publicado'
        ).exclude(id=post.id)[:4]
        
        # Dados para o sidebar
        context['categorias'] = Categoria.objects.annotate(
            num_posts=Count('posts', filter=Q(posts__status='publicado'))
        )
        context['posts_recentes'] = Post.objects.filter(
            status='publicado'
        ).exclude(id=post.id).order_by('-publicado_em')[:5]
        
        return context


class PostsPorCategoriaView(ListView):
    """
    View para listar posts de uma categoria específica.
    """
    model = Post
    template_name = 'blog/posts_por_categoria.html'
    context_object_name = 'posts'
    paginate_by = 9
    
    def get_queryset(self):
        """
        Filtra posts da categoria especificada.
        """
        slug = self.kwargs.get('slug')
        categoria = get_object_or_404(Categoria, slug=slug)
        
        return Post.objects.filter(
            categoria=categoria,
            status='publicado'
        ).select_related('autor', 'categoria')
    
    def get_context_data(self, **kwargs):
        """
        Adiciona informações da categoria ao contexto.
        """
        context = super().get_context_data(**kwargs)
        slug = self.kwargs.get('slug')
        context['categoria'] = get_object_or_404(Categoria, slug=slug)
        
        context['categorias'] = Categoria.objects.annotate(
            num_posts=Count('posts', filter=Q(posts__status='publicado'))
        )
        context['posts_recentes'] = Post.objects.filter(
            status='publicado'
        ).order_by('-publicado_em')[:5]
        
        return context


@login_required(login_url='login')
def comentario_criar(request, slug):
    """
    View para criar um novo comentário em um post.
    
    - login_required: Apenas usuários autenticados podem comentar
    - Cria o comentário e redireciona de volta ao post
    """
    post = get_object_or_404(Post, slug=slug, status='publicado')
    
    if request.method == 'POST':
        conteudo = request.POST.get('conteudo', '').strip()
        
        # Validação básica
        if conteudo and len(conteudo) > 10:
            Comentario.objects.create(
                post=post,
                autor=request.user,
                conteudo=conteudo
            )
    
    return redirect('post_detail', slug=slug)


@login_required(login_url='login')
def comentario_editar(request, pk):
    """
    View para editar um comentário existente.
    """
    comentario = get_object_or_404(Comentario, pk=pk)
    
    # Apenas o autor pode editar
    if request.user != comentario.autor:
        return redirect('post_detail', slug=comentario.post.slug)
    
    if request.method == 'POST':
        conteudo = request.POST.get('conteudo', '').strip()
        if conteudo and len(conteudo) > 10:
            comentario.conteudo = conteudo
            comentario.save()
    
    return redirect('post_detail', slug=comentario.post.slug)


@login_required(login_url='login')
def comentario_excluir(request, pk):
    """
    View para excluir um comentário.
    """
    comentario = get_object_or_404(Comentario, pk=pk)
    post_slug = comentario.post.slug
    
    # Apenas o autor ou admin podem excluir
    if request.user == comentario.autor or request.user.is_staff:
        comentario.delete()
    
    return redirect('post_detail', slug=post_slug)
```

**Explicações Importantes:**

1. **`ListView`**: Classe para exibir listas de objetos com suporte automático a paginação[10]

2. **`DetailView`**: Classe para exibir detalhes de um objeto único[10]

3. **`select_related()`**: Otimiza queries fazendo um LEFT OUTER JOIN, reduzindo quantidade de consultas ao banco[10]

4. **`annotate()`**: Adiciona campos calculados aos resultados (como contagem)[10]

5. **`Q objects`**: Permite queries complexas com operadores OR (`|`) e AND (`&`)[10]

6. **`@login_required`**: Decorador que restringe acesso apenas a usuários autenticados[10]

## 9. Criação das URLs

As URLs fazem o mapeamento entre endereços web e views. Crie/edite `blog/urls.py`:

```python
# blog/urls.py
from django.urls import path
from . import views

app_name = 'blog'  # Namespace para evitar conflitos com outras apps

urlpatterns = [
    # Listagem de todos os posts
    path(
        '', 
        views.PostListView.as_view(), 
        name='post_list'
    ),
    
    # Detalhes de um post específico (usando slug)
    path(
        'post/<slug:slug>/', 
        views.PostDetailView.as_view(), 
        name='post_detail'
    ),
    
    # Listagem de posts por categoria
    path(
        'categoria/<slug:slug>/', 
        views.PostsPorCategoriaView.as_view(), 
        name='posts_por_categoria'
    ),
    
    # Criar comentário
    path(
        'post/<slug:slug>/comentario/', 
        views.comentario_criar, 
        name='comentario_criar'
    ),
    
    # Editar comentário
    path(
        'comentario/<int:pk>/editar/', 
        views.comentario_editar, 
        name='comentario_editar'
    ),
    
    # Excluir comentário
    path(
        'comentario/<int:pk>/excluir/', 
        views.comentario_excluir, 
        name='comentario_excluir'
    ),
]
```

### Registrar URLs da App no Projeto

Agora você precisa incluir essas URLs no arquivo principal do projeto. Abra `seu_projeto/urls.py`:

```python
# seu_projeto/urls.py
from django.contrib import admin
from django.urls import path, include
from django.conf import settings
from django.conf.urls.static import static

urlpatterns = [
    path('admin/', admin.site.urls),
    path('blog/', include('blog.urls')),  # Incluir URLs do blog
]

# Servir arquivos de mídia em desenvolvimento
if settings.DEBUG:
    urlpatterns += static(settings.MEDIA_URL, document_root=settings.MEDIA_ROOT)
    urlpatterns += static(settings.STATIC_URL, document_root=settings.STATIC_ROOT)
```

**Explicação dos Conversores de URL:**

```
path('post/<slug:slug>/', ...)
        └─── Converte 'slug' para string com números, letras, - e _

path('comentario/<int:pk>/', ...)
        └─── Converte 'pk' para inteiro

path('categoria/<str:nome>/', ...)
        └─── Converte 'nome' para string (padrão se não especificado)
```

**Padrão de URL Gerado:**

```
/blog/                          → PostListView (lista todos os posts)
/blog/post/meu-primeiro-post/   → PostDetailView (detalhes)
/blog/categoria/django/         → PostsPorCategoriaView
/blog/post/meu-primeiro-post/comentario/  → Criar comentário
```
